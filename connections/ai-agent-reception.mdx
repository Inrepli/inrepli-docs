---
title: AI Agent Reception
description: Help compatible AI assistants discover and contact your website assistant.
---

Open your site under **Website → AI Agent Reception**. Start with an active website with a connected website assistant and active knowledge sources. When reception is available, turn on **Accept consultations from external AI assistants**.

## Choose how to publish discovery information

- **Automatic via SDK** uses your installed Inrepli SDK to add links to the selected Inrepli-hosted discovery files. Enable **Browser WebMCP** if you want compatible browsers to expose the consultation tool directly.
- **Download and publish yourself** provides file previews, individual downloads, a ZIP and website link code. Publish the files on your own website and merge them with existing files of the same name. Keep the `.well-known` directory when publishing the Poppy discovery file. Open the published addresses to check that each file is reachable.

You can also add static links so clients that do not run page scripts can find the files. Update or remove copies that you host yourself. Turning off reception stops the consultation service.

## Try a consultation

Use **Test guide** to copy a business question and website address to a compatible assistant. Open **Conversations** to compare the exchanged messages. On a site configured for AI booking, use the booking example and confirm the exact time before the assistant books it. Open the meeting card in the conversation to check the scheduled time.
