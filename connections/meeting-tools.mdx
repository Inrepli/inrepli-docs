title: Meeting Tools

---
## Overview

Inrepli can create meeting links using the video conferencing tools your team already uses.

Supported meeting tools include Google Meet, Zoom, and Microsoft Teams. When the Agent schedules a Meeting, the meeting link is added to the calendar invitation and shared with both the Contact and the assigned Account Manager.

## Account Manager Selection

Each Account Manager can choose their preferred meeting tool.

This allows different team members to use different tools within the same Inrepli workspace. For example, one Account Manager may use Zoom while another uses Microsoft Teams.

When a Contact books a Meeting, Inrepli uses the meeting tool connected by the assigned Account Manager.

## Meeting Invitations

The meeting invitation includes:

- The meeting date and time
- The Contact and Account Manager
- The meeting link
- Relevant Meeting details

Using the Account Manager’s connected meeting tool creates a consistent scheduling experience and reduces the need to create meeting links manually.
