## Overview

Inrepli connects with the calendar tools your team already uses so the Agent can check availability and schedule Meetings without creating conflicts.

Calendar connections are managed separately for each Account Manager. This allows every Account Manager to connect the calendar they use to manage their own schedule.

## Account Manager Calendars

Each Account Manager can select and connect their preferred calendar.

When the Agent is ready to schedule a Meeting, Inrepli checks the assigned Account Manager’s connected calendar and only presents times that are available within both the Account Manager’s Inrepli availability settings and their external calendar.

This allows different Account Managers in the same workspace to use different calendar tools.

## Calendar Synchronization

Calendar Integrations support two-way synchronization for Meetings scheduled through Inrepli.

When an Inrepli Meeting is booked, rescheduled, or cancelled, the related calendar event is updated in both Inrepli and the connected calendar where supported.

Inrepli only stores and synchronizes detailed information for Meetings created through the Inrepli Agent. Other events in the connected calendar are used to determine availability but are not imported into the Inrepli workspace.

## Supported Calendar Tools

Inrepli supports the following calendar and scheduling tools:

- Google Calendar
- Microsoft Outlook Calendar
- Calendly
- [Cal.com](https://cal.com)

The available scheduling behavior may vary depending on the connected tool. Google and Microsoft calendar connections can be used to check calendar availability and synchronize Inrepli Meetings. Calendly (paid versions) and [Cal.com](https://cal.com) can be used when an Account Manager prefers to share an existing scheduling link.
