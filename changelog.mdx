## Recent Updates

Stay informed about the latest improvements to Inrepli Docs. Review release notes below to understand new features, bug fixes, and any required actions.

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "improvement"]}>

## New Features

- Added support for custom knowledge bases in agent configurations.
- Introduced WhatsApp follow-up integration for multi-channel capture.

## Improvements

- Enhanced lead qualification logic with better intent detection.
- Optimized unified inbox loading times by `>30%`.

## Bug Fixes

- Fixed routing errors when multiple owners match qualification rules.
- Resolved profile enrichment failures for certain company domains.

</Update>

<Update label="2024-09-20" description="v1.1.0" tags={["feature", "bugfix"]}>

## New Features

- Launched training tools dashboard to identify knowledge gaps.
- Added meeting booking calendar sync with Google Workspace.

## Bug Fixes

- Corrected email follow-up threading issues.
- Patched security vulnerability in webhook endpoints.

## Improvements

- Streamlined setup agent to auto-detect website forms.

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Initial Release

- Core inbound agent with lead capture and qualification.
- Unified inbox and basic lead routing.

## Breaking Changes

- Updated API authentication to use `{API_KEY}` headers only.

</Update>

<Callout kind="alert">
  For v1.0.0 users, migrate to the new authentication format immediately to avoid disruptions.
</Callout>

## Migration Guide

Follow these steps to upgrade smoothly between versions.

<Steps>
  <Step title="Backup Configuration" icon="database">
    Export your current agent settings and knowledge base.
  </Step>
  <Step title="Update Package" icon="download">
    <CodeGroup tabs="npm,yarn">
````bash
npm install inrepli-docs@latest
````
````bash
yarn add inrepli-docs@latest
````
    </CodeGroup>
  </Step>
  <Step title="Review Breaking Changes" icon="alert-triangle">
    Check the `{API_KEY}` header update in v1.0.0 notes.
  </Step>
  <Step title="Test Integrations" icon="zap">
    Verify WhatsApp and email follow-ups in staging.
  </Step>
</Steps>
