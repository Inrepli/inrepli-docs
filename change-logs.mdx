## Smarter qualification and clearer customer activity

This release gives teams more control over buyer qualification and clearer context from website and form activity.

### Buyer Readiness questions

- Configure required and optional qualification questions for Budget, Authority, Need, Timeline, or other criteria.
- Connect each question to a compatible Contact field so the Agent can collect answers during Conversations.
- Use an Agent suggestion as a starting point when setting up a question.

### Consent-aware website activity

- Collect website activity only when website tracking is enabled and the required consent is available.
- Review website and form activity in a Contact's profile after the visitor is identified.
- Preserve form-submission activity more reliably when the form navigates to another page.

### Setup and lifecycle reliability

- Website setup and refresh work recovers more reliably after interruptions.
- Playground and billing lifecycle emails avoid duplicate delivery and stop when they are no longer applicable.
