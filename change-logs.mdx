### Web Chat customization and content

Administrators can adjust the website chat's appearance, launcher, welcome content and reply suggestions in [Web Chat Settings](/connections/website-sdk). Save changes as a personal draft, preview desktop and mobile layouts, and review the changes before publishing. The Support Agent can prepare a draft and request publication; publishing still requires confirmation in the platform.

Visitors can open supported images, videos, PDFs, presentations and embedded webpages from the conversation without losing the chat. On wider screens, content opens beside the chat; on smaller screens, visitors can return from the content to the conversation.

### Website visitor insights and reception

Website activity includes an updating visit summary and traffic information for identified AI agents, crawlers and automation. Configure how the website Agent handles automated visitors and whether supported AI agents may book meetings. AI booking requires verified traffic, an existing contact and a trusted email address.

Enable proactive reception to offer a relevant invitation based on a visitor's activity. Invitations respect the visitor's typing and conversation state and can be dismissed.

### Qualification and business research

Qualification uses configured criteria, available company research and the contact's current answers. Required questions remain incomplete when unanswered or explicitly skipped. Company and Contact enrichment uses AI-assisted web research and profile summaries.

### Knowledge and conversation handling

Website Agent replies can include verified resources linked to the knowledge used for the answer. Supported files are delivered as attachments or content cards; an invalid media reference does not discard the text answer.

Website Agent conversations retain relevant messages from the current visit more consistently. Inbox shows traffic identity separately from Spam classification, with a **Not Spam** action for incorrectly flagged conversations.

### Web Chat tools for connected assistants

Connected assistants can find website widgets, read published settings and draft Web Chat changes. Publication requests return a platform confirmation action rather than silently changing the live chat. See [MCP tools](/mcp/tools).
