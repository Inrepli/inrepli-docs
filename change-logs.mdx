# Changelog

Product updates, improvements, and fixes from Inrepli.

<Update label="2026-09-18" description="Connected customer data, clearer feedback follow-up, and easier team setup" tags={["feature", "improvement"]}>

## Connected customer workflows

This release adds new ways to connect Inrepli with business systems and AI assistants, gives product feedback a clearer follow-up path, and makes Playground collaboration easier.

### REST API and MCP connections

- Use REST API 1.1 to list, read, filter, and update supported Contact and Company data, and to read team members and custom field definitions.
- Connect compatible AI assistants through MCP with personal OAuth authorization and the signed-in user's current CRM permissions.
- Review API and MCP setup guidance, credentials or connections, usage, and call logs from the Connections area.

### Support feedback and follow-up

- Report a bug, request a feature, or suggest an improvement through the Inrepli Assistant from signed-in product pages.
- See a confirmation in the conversation when feedback is captured. When an email address is available, Inrepli can also send an acknowledgement and a follow-up after the product team addresses the request.

### Playground and customer data

- Invite teammates from the Playground with a selected workspace role and a message you can edit before sending.
- Open the Inrepli Platform, Inbox, or current Contact profile directly from a Playground conversation.
- Buyer Readiness questions now use dedicated Contact fields. These managed fields link back to their source question and are edited from the question settings.
- Eligible live Growth workspaces can enable website behavior tracking at go-live; when consent setup is still required, Inrepli creates a setup task before tracking is enabled.

### Experience improvements

- Improved conversation Markdown, field loading, activity descriptions, color contrast, and meeting-link validation make everyday review and response workflows clearer.
