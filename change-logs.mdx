<Update label="September 4, 2026" description="Qualification and website activity updates" tags={["feature", "improvement"]}>

## More consistent buyer qualification

- Configure Buyer Readiness Questions for the information your Agent should collect during inbound Conversations.
- Mark questions as required or optional, connect each answer to a compatible Contact field, and use Agent suggestions to help prepare the question and field configuration.
- Required questions are collected before final qualification and automated meeting booking, while optional questions add context without delaying those steps.

## Clearer, consent-aware website activity

- Review website page views, form submissions, and interactions from the Website workspace, with filters for activity type and date.
- See website and form activity connected to the relevant Contact so your team has more context when reviewing an inquiry.
- Connect supported consent tools or a custom consent integration so tracking follows the scopes required for each website.

## More reliable setup and communications

- Website setup work is recovered more safely when processing is interrupted or a website is removed.
- Lifecycle email handling reduces duplicate delivery and keeps cancellation and unsubscribe behavior consistent.
